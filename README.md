## Featured Projects

### Alpha_Chess — AI Chess Engine

A Python-based chess engine with an interactive Pygame interface. The AI selects moves using NegaMax search with alpha-beta pruning and a material-plus-positional evaluation.

- Custom move generation covering checks, pins, castling, en passant and pawn promotion
- Fixed-depth (4) AI search with move ordering and alpha-beta pruning
- Board evaluation using piece values and piece-square tables
- Interactive GUI with move animations, move history, highlighting, undo and reset
- AI runs in a separate process to keep the interface responsive
- Checkmate and stalemate detection

**Tech Stack:** `Python` `Pygame` `Multiprocessing` `PyInstaller`

---

### PyOS — Operating System Simulator

A modular, Python-based operating system simulator with an interactive command-line shell. It demonstrates user accounts, filesystem permissions, process management and task scheduling. It runs as a Python application and is not a bootable OS.

- User login with admin/user roles and bcrypt-hashed passwords
- Per-user workspaces with file operations and Unix-style permission modes
- Shell with history, environment variables, pipes, redirection and command chaining
- Simulated process/job management with PIDs and ownership checks
- Timer-based delayed commands, simulated service controls and package tracking
- Persistent state via SQLite and JSON, with a `unittest` suite

**Tech Stack:** `Python` `SQLite` `bcrypt` `JSON` `threading` `pathlib` `shlex` `subprocess` `unittest`
